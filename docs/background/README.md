# 研究背景

本目录是论文工作的背景快照，不是本仓库的工程规格。工程规格从 [`../00-overall-design.md`](../00-overall-design.md) 读起，验收状态见 [`../91-roadmap.md`](../91-roadmap.md)。

## 这份代码在主张什么

SciTeam 要做一个可以真实使用的多智能体系统，同时当作系列论文的实验平台。科学问题是：解释器冻住之后，只改配置文件（harness、通信策略、制度规则、组织结构），行为和结果如何变化。

制度层回答的不是「下一步跑谁」，而是：谁有资格行动、什么产物算数、依据哪一版规则、规则怎样合法修改。图和 harness 仍然负责执行。制度叠加上去，不换掉它们。

更完整的定义、不主张清单和文献划界在 [`00-charter.md`](00-charter.md)。英文论文草稿在 [`23-arxiv-draft-v1.md`](23-arxiv-draft-v1.md)。

## 和已废弃分支的关系

GitHub 上的 `abandoned/sciteam-v1` 是 2026-09 公开的上一版运行时。那一版用脚本化席位做了存在性证明（未授权提交不生效、审计否决后合法重开、修宪不改解释器），并配了插件、账本和参考界面。论文草稿 §5 的复现入口在那条分支上，不在本仓库。

2026-09-23 起代码从零重写，不继承旧实现。建造顺序是单 agent harness、通信、制度、组织、实验，每一层都要先通过真实模型验收。前四层已经关闭。第五层正在用 Commit0 检验：机械验证、权力分立和合法恢复，在真实模型占据席位时是否仍各自挡住一种失败。
