# Mission & paradigm notes

Missions are the unit of team work. Paradigms are coordination templates.
See HARNESS.md §1–§4.

## Example mission kinds (catalog, not engine enums)

| kind | Typical paradigms | Exit contract (example) |
|---|---|---|
| `protocol` | pipeline_chain | `protocol.yaml` |
| `topic` | survey_gather | `topic_choice.json` + `lit_map.json` |
| `hypothesis_atelier` | brainstorm_swarm → debate_elo → smoke | `candidate_hypotheses.json` |
| `design` | debate_elo or pipeline_chain | `design.md` + ablation plan |
| `build_fix` | build_fix_loop | `results.json` (mission-local or official) |
| `adversarial` | adversarial_pair | `attack_report.md` |
| `write` | write_atelier | manuscript + checklist |
| `wrap_up` | write_atelier (honest) | best-effort package |

Campaign planner may repeat, skip, or reorder these freely under budget.
