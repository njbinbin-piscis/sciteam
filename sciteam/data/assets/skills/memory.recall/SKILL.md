# Skill: memory.recall

## Purpose
Use bounded same-seat memories to avoid repeating disproven methods.

## Steps
1. Read the injected Same-seat memory section before selecting a method.
2. Match memories by failure mode and evidence, not superficial wording.
3. Reuse an effective fix only when its assumptions still hold.
4. If the current evidence contradicts memory, preserve the new counterexample
   and choose a different method.

## Stop
Proceed with a method that addresses relevant counterexamples, or escalate with
the memory record and the missing information.
